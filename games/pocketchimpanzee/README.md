# pocketChimpanZee_OJ

ゲームボーイ風の筐体シミュレータ内で動作する、レトロなモンスター育成・バトルRPGゲームのPoC開発プロジェクトです。

## プロジェクト構成

このプロジェクトは、筐体デザイン（Interface）とゲーム本体（Game）を分離したモジュール設計になっています。

```text
C:\Users\Chimpanzee\Desktop\projectC\games\pocketchimpanzee\
  ├── index.html            (エントリポイントHTML)
  ├── app.js                (全体コーディネーター＆インプット仲介)
  ├── README.md             (このファイル)
  ├── game/                 (ゲーム本体のロジック・画面)
  │     ├── game.js         (共通ステート管理・効果音合成・ゲーム進行)
  │     └── game.css        (液晶画面内のドット絵風デザイン・アニメーション)
  └── interfaces/           (仮想筐体デザイン・スキン)
        ├── landscape/      (横長大画面スキン - 左右リボン形式)
        │     ├── layout.js
        │     └── style.css
        └── portrait/       (縦型クラシックスキン - 初代ゲームボーイ風)
              ├── layout.js
              └── style.css
```

## 開発ロードマップ

1.  **オープニング (game/opening/)**：[進行中]
    *   タイトル画面（ロゴアニメーション、セーブデータの有無による「はじめから / つづきから」の分岐）
    *   プレイヤー名・ライバル名の決定
    *   プロローグ（おなじみの博士の紹介メッセージ）
2.  **マップ移動 (game/map/)**：
    *   レトロなドット絵風のフィールド（街、草むら、家の中など）のスクロール歩行
    *   NPCとの対話メッセージ、ドアや階段によるマップ移動
    *   草むらでのランダムエンカウントによるバトル遷移
3.  **戦闘システム (game/battle/)**：
    *   コマンド選択式（たたかう、バッグ、ポケモン、にげる）のターン制戦闘
    *   味方・敵モンスターのHPゲージ、ステータス、属性相性
    *   戦闘勝利時の経験値獲得、レベルアップ、セーブデータ書き込み
4.  **共通機能 (game/shared/)**：
    *   `localStorage` を使ったセーブデータ保存/ロード処理

---

## 遊び方・確認方法

1.  [index.html](index.html) をブラウザで開きます。
2.  画面をクリックして電源を入れると、起動デモが再生されます。
3.  [app.js](app.js) の `ACTIVE_INTERFACE` の文字列を変更することで、筐体の外観（`landscape` / `portrait`）をいつでも切り替えることができます。
