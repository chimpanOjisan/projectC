# ちんぱんのちんぱんによるちんぱんのためのりぽじとり

## 今後の作業・後段のタスクに必要なこと

このリポジトリの各開発テーマを進めるにあたり、以下の情報定義や初期化作業が必要です。

### 1. analytics (データ分析・projectM)
- **Causalimpact (因果効果検証)**:
  - 使用する言語（R / Python等）の選定
  - 分析対象となるデータソース（CSV、データベース等）の準備と配置
  - 分析コード（Jupyter Notebookやスクリプト）の作成
- **LTV (顧客生涯価値予測)**:
  - LTV予測モデルの定義（統計モデル、機械学習モデル等）
  - 予測に必要なユーザー行動データ、購買データの整理

### 2. games (ゲーム開発)
- **pocketChimpanZee_OJ (ゲームボーイ風モンスター育成RPG)**:
  - 開発方針：モジュール分割設計。筐体（`interfaces/`）とゲーム画面・ロジック（`game/`）を分離。
  - 開発ロードマップ：
    1. **オープニング (game/opening/)**：タイトル画面、つづきから/はじめから、セーブデータ管理、プロローグ等。 (←現在の開発対象)
    2. **マップ移動 (game/map/)**：フィールド探索、歩行、NPC会話、エンカウント処理。
    3. **戦闘システム (game/battle/)**：コマンドバトル、モンスター遭遇、属性相性、育成・レベルアップ。
  - 使用技術：HTML/CSS/JavaScript (CORS回避のための静的読み込み設計)

### 3. ３D_printer (3Dプリンター・create_crab/ガザミ)
- ガザミ（カニ）のCADモデリングデータの設計
- 使用する3Dデータフォーマット（STL、OBJ、またはOpenSCAD等のコードベース）の決定とファイルの配置
